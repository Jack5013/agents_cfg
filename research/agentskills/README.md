# agentskills 本地资料库

## 目的
- 减少重复联网抓取成本。
- 固化可复用的规范与高价值写法，供主 Agent 与 subagent 提示词持续迭代。

## 分类
- `specification-summary.md`：Agent Skills 规范摘要（格式、目录、渐进加载、校验）。
- `popular-process-skills-2026-03-09.md`：agentskills.me 热门流程型技能筛选与评估。
- `cache-policy.md`：本地缓存更新策略与清理规则。
- `selections/`：按日期保存正式筛选结论。
- `style-maps/`：写法映射文档（来源 -> 分工 agent）。
- `weekly-reviews/`：每周巡检报告（按模板执行）。

## 使用方式
- 需要更新时优先增量更新单文件，不整库重抓。
- 新增调研记录命名建议：`<topic>-YYYY-MM-DD.md`。
